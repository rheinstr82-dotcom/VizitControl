# Учёт абонементов — веб-приложение (PWA)

Устанавливается на Android как обычное приложение — с иконкой на рабочем столе,
без Google Play и без Android Studio. Работает офлайн, данные хранятся в браузере
на телефоне.

## Файлы

```
index.html          — само приложение
manifest.json        — описание приложения для установки (имя, иконки, цвета)
service-worker.js    — офлайн-кэш
icons/                — иконки разных размеров
```

## Как выложить на GitHub Pages

1. Создайте новый репозиторий на github.com (например, `attendance-app`).
2. Загрузите в него все файлы из этой папки (`index.html`, `manifest.json`,
   `service-worker.js`, папку `icons/`) — через веб-интерфейс GitHub
   (`Add file → Upload files`) или через `git push`.
3. Зайдите в `Settings → Pages`.
4. В разделе **Source** выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты GitHub покажет ссылку вида:
   `https://ВАШ_ЛОГИН.github.io/attendance-app/`

## Как установить на Android

1. Откройте полученную ссылку в **Chrome** на телефоне.
2. Chrome сам предложит баннер «Установить приложение» — либо откройте меню
   (⋮ в правом верхнем углу) → **«Установить приложение»** / **«Добавить на главный экран»**.
3. Готово — на рабочем столе появится иконка с билетиком, приложение открывается
   в полноэкранном режиме, как обычное нативное.

## Обновление

Чтобы обновить приложение после установки — просто загрузите новые файлы в тот же
репозиторий на GitHub. Service worker подхватит изменения при следующем открытии
(иногда телефону нужно открыть приложение дважды, чтобы кэш обновился).

## Важно про данные

Все люди, абонементы и история посещений хранятся **локально в браузере телефона**
(localStorage). Если очистить данные браузера/приложения или переустановить —
записи пропадут. Данные не синхронизируются между устройствами.
